# Отчёт по выявленным событиям

## Подозрительные события

1. **Доступ к секретам**:
    - **Кто**: minikube-user
    - **Что**: запрашивал list секретов в неймспейсе kube-system
    - **Почему подозрительно**: обычный пользователь не должен иметь прав на просмотр секретов.
      Несколько повторных попыток могут говорить о целенаправленной попытке их получить.

2. **Создание RoleBinding**:
   - **Кто**: minikube-user
   - **Что**: успешно создал RoleBinding с именем escalate-binding в secure-ops
   - **Почему подозрительно**: пользователь явно смог добиться повышения привелегий.

3. **Создание подозрительного пода**:
   - **Кто**: minikube-user
   - **Что**: создал под attacker-pod в неймспейсе secure-ops
   - **Почему подозрительно**: Пользователь, который отметился подозрительной активностью смог создать под.

4. **Создание подозрительного пода**:
   - **Кто**: minikube-user
   - **Что**: создал под coredns в неймспейсе kube-system
   - **Почему подозрительно**: Выглядит попыткой подменить днс-сервер своим, с учетом обнаруженной ранее активности.

## Вывод

Анализ показал вероятную атаку со стороны пользователя minikube-user, которая включала попытки листинга
секретов, повышение привилегий (RoleBinding с именем escalate-binding), запуск подозрительных контейнеров и
попытку подмены днс сервера.
